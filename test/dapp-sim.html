MoneyNex.info

—

sdk.md: MoneyNexInit callback or polling window.MoneyNex. MoneyNex.info.version must equal the manifest version.

connect

—

Success → {address}; user cancel → reject {ret:1, code:'user_canceled'}; already authorized → immediate {address}, no window.

wallet

—

Authorized → {address}; unauthorized → reject {err:'need connect first', code:'need_connect'} (and the wallet opens a connect window).

chain (read-only)

—

Never opens a page, never requires connect. Returns current/target chain, configured, matched, need_add, need_switch, diff.

switchchain

—

Already current → {already_current:true, switched:false}. User reject → {err:'User rejected network switch'}; unconfigured in `switch` mode → {err:'Chain not configured', need_add:true}.

transfer

—

Builds {actions:[{kind:1, to, amount}]} → btoa → {txobj}. Success → {ret:0, success:true, submit:true, txhash,…}. Submit rejected by node → {ret:1, code:'submit_failed'}.

signtx

—

Review presets are unsigned and never autosubmit. The sourcemap fixture has two identical IR maincalls with different labels and one nested maincall.

signtext

—

Success → {ret:0, digest, public_key, signature, address}. 8..4096 chars enforced; 64-hex / 43-char base64 payloads are always refused.

raisefee

—

Success → {ret:0, success:true}. Unknown hash / node rejection surfaces as an error reply.

Events (MoneyNex.on / MoneyNexDisconnect)

—

sdk.md events: MoneyNex.on('disconnect', cb) → cb({origin}) AND window 'MoneyNexDisconnect' CustomEvent, fired when this site's connection is revoked (wallet Connected indicator or connected-sites management).
